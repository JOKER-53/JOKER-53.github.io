# KADHIRAVANEG - Personal Portfolio

This is the personal portfolio and website of Kadhiravan E.G, a developer and Linux enthusiast focusing on building robust security tools, educational platforms, and exploring system internals.

## Tech Stack

The project is built using fundamental web technologies for a lightweight, performant, and dependency-free experience:
- **HTML5**: Semantic structure
- **CSS3**: Custom styling with a dark/light theme system and modern flex/grid layouts. Extracted to `styles.css`.
- **Vanilla JavaScript**: Interactive elements like typed text, scrolling effects, and dynamic GitHub API data fetching. Extracted to `script.js`.

## Features

- **Dynamic GitHub Data**: Automatically fetches and updates the repository count from GitHub API.
- **Projects Showcase**: Highlights flagship systems like FLAMES and Intelligent Compiler.
- **Interactive Cyber Range**: A built-in mini-game utilizing canvas on the background.
- **Command Palette**: Quick navigation (Ctrl+K).
- **Responsive Design**: Mobile-friendly navigation and layout.

## Setup

No build tools or package managers are required. Simply clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/KADHIRAVANEG/KADHIRAVANEG.github.io.git
cd KADHIRAVANEG.github.io
# Open index.html in your favorite browser
```
